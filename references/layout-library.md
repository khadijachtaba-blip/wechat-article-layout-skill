# 公众号场景与高质量版式库

## 1. 使用方法

先确定唯一主 `scene`，再从该场景的三个方向中组合首屏、章节、重点模块和图片节奏。场景决定阅读任务，风格变体决定视觉表现。

规则：

1. 不给一个场景绑定唯一模板。
2. 成熟组件可以复用，但同一整套首屏、章节和模块不得跨文章无差别复制。
3. 三套推荐在首屏、章节、重点模块、图片节奏、结尾/指南中至少三项不同。
4. 原稿缺少图片、数据、引语或流程时删去对应模块，不虚构素材。
5. 场景差异不得降低审美完成度；新组件弱于成熟样式时重新组合。

## 2. 基础阅读骨架

| layout | 阅读任务 | 基础骨架 |
| --- | --- | --- |
| `briefing` | 快速掌握背景、要点和结论 | 摘要—要点—结论 |
| `minimal-news` | 连续阅读事实 | 标题—导语—正文—图片—结尾 |
| `tech-brand` | 理解能力、流程和数据 | 问题—能力—流程—结果 |
| `business-report` | 理解合作、成果和影响 | 背景—合作—里程碑—影响 |
| `event-story` | 跟随活动或现场阅读 | 场景—过程—高光—结果/指南 |
| `education-warm` | 理解对象、过程和成长 | 情境—过程—体验—成果 |
| `editorial` | 阅读人物、观点和深度故事 | 强首屏—叙事—引语—收束 |
| `culture-story` | 感受文化、文旅和生活方式 | 画面—叙事—价值收束 |

## 3. 场景配方

### 政务调研 `official-briefing`

- 公文简报：白底大标题＋事实行；规则线章节；调研摘要、问题和结论。
- 现代新闻：报头首屏；无编号短标题；连续正文、图片图注和引语。
- 克制报告：窄深色锚点；矩形索引标题；要点清单和下一步。
- 配色：深蓝、灰蓝、少量金色或红色；少圆角、少装饰。

### 新闻通稿 `news-release`

- 新闻报头：标题＋导语＋事实行；短标题＋底线；事实摘要和图片图注。
- 品牌发布：深色或大字号首屏；简洁色线标题；单个数据锚点。
- 杂志新闻：大留白标题；无编号章节；引语、图片和正文交替。
- 配色：黑白灰＋一个主题色；阅读优先。

### 党建学习 `party-study`

- 红色文献：米白首屏＋红色框线；方形序号＋金色细线；学习要点和原文摘录。
- 现代党刊：大标题＋克制红色区块；无编号短标题；引语和行动清单。
- 学习简报：摘要前置；规则线标题；要点清单和庄重收束。
- 配色：庄重红、米白、少量金色；避免节庆化和大面积金色渐变。

### 科技产品 `product-launch`

- 产品控制台：深浅分区首屏；大号技术编号；能力矩阵、流程链和数据。
- 国际科技：大字号白底首屏；轨道线标题；问题—能力—结果对照。
- 极简发布：单色深色首屏；无编号短标题；单列功能、流程和结论。
- 配色：科技蓝、蓝绿、冷暖小面积对比；不默认蓝紫发光。

### 战略合作 `strategic-cooperation`

- 商务框架：双方信息分层首屏；矩形索引标题；合作清单、里程碑和影响。
- 签约新闻：报头首屏；短线标题；事实、发言和下一步。
- 当代商务：深色锚点＋大留白；直角标题；合作内容和结论模块。
- 配色：深蓝、灰蓝、少量金色；直角或小圆角。

### 活动回顾 `event-recap`

- 图片纪实：首图先行；时间戳章节；图片叙事、现场引语和成果。
- 品牌复盘：深色活动首屏；色线标题；高光、数据和图文交替。
- 城市杂志：大标题＋留白；无编号章节；大图、短段和引语。
- 配色：由活动气质决定；多图时减少装饰。

### 活动招募 `event-recruitment`

- 信息海报：标题、日期、地点和对象分区；居中标题；步骤、赛程和提醒。
- 品牌活动：深色首屏；简洁色线标题；亮点、日程和参与指南。
- 轻量日历：日期先行；阶段标签标题；日程条和报名信息。
- 配色：保持行动感；信息必须清楚，不能把长正文塞进首屏。

### 教育案例 `education-research`

- 案例档案：标题＋对象＋目标；课题标签标题；过程阶梯、引语和成果。
- 教育品牌：柔和深色首屏；简洁色线标题；方法、体验和结果。
- 温暖杂志：大留白标题；无编号章节；真实图片、短段和引语。
- 配色：蓝绿、清新蓝或低饱和暖色；不幼稚、不卡通化。

### 政策解读 `policy-explainer`

- 政策备忘录：政策名称＋适用对象＋摘要；问题式标题；要点、影响对象和行动清单。
- 官方问答：白底大标题；主题词标题；“是什么—影响谁—怎么做”。
- 现代报告：窄深色首屏；规则线标题；原文摘录、解释框和结论。
- 配色：权威、清晰、低装饰；不用渐变制造权威感。

### 人物故事 `people-story`

- 编辑封面：人物名或主题超大呈现；大序号标题；肖像、引语和时间脉络。
- 人物纪实：图片先行；无编号短标题；经历片段和侧记。
- 黑白杂志：强留白首屏；衬线标题；大引语和克制收束。
- 配色：黑白灰＋低饱和暖色；减少卡片和渐变。

### 生活活动 `lifestyle-event`

- **夏夜品牌专题（质量基准）**：深色品牌首屏；浅色导语卡；简洁色线标题；日程模块；单个深色数据锚点；圆角参与指南。
- 城市生活杂志：大字号白底首屏；无编号短标题；图文交替；活动信息集中在文末。
- 轻盈日历编辑：日期、地点、标题分区；阶段标签标题；日程条和轻量指南。
- 配色：可使用夜蓝＋绿色＋暖橙、自然绿＋米白＋橙色或黑白＋主题色；不要默认浅米色顶栏配多处虚线。

### 文化文旅 `culture-journey`

- 沉浸画面：大图或场景文字先行；居中宋体标题；图片叙事和价值收束。
- 当代文化：大字号白底首屏；细线标题；引语、过程和图片。
- 文旅杂志：目的地/场景先行；无编号章节；行程、体验和图片节奏。
- 配色：低饱和、舒展；避免仿古纹样堆叠。

## 4. 视觉变体参数

生成计划可以使用：

| 参数 | 推荐值 | 作用 |
| --- | --- | --- |
| `hero_variant` | `scene-default`、`brand-gradient`、`editorial-light`、`calendar-blocks`、`ui-dashboard`、`split-gradient` | 首屏形态 |
| `section_variant` | `scene-default`、`accent-line`、`editorial-rule`、`label-rule`、`ui-index`、`number-stack`、`gradient-underline` | 一级章节标题 |
| `metrics_variant` | `scene-default`、`dark-feature`、`stacked-facts`、`light-grid` | 数据/事实模块 |
| `steps_variant` | `scene-default`、`rounded-cards`、`schedule-list`、`ticket-list`、`ui-rail` | 步骤/指南 |
| `emphasis_variant` | `scene-default`、`gradient-statement`、`editorial-statement`、`ui-notice` | 金句/核心陈述 |
| `points_variant` | `scene-default`、`ui-list`、`index-grid`、`plain-checklist` | 并列要点 |

同一篇文章使用一种主章节样式和一套主要圆角。只有活动指南、附录或工具性信息与正文阅读任务明显分离时，才允许第二种功能性标题或边界。

## 5. 模块选择

| 原稿内容 | 模块 | 约束 |
| --- | --- | --- |
| 核心摘要 | `callout` | 只出现1–2次 |
| 可传播原句/核心价值句 | `keyline` | 通常1–3句，不虚构口号 |
| 章节内局部小标题 | `subheading` | 强度必须低于一级章节 |
| 结构化并列要点 | `keypoints` | 2–6项，保持同一逻辑层级 |
| 精确数据 | `metrics` | 可用深色锚点、事实条或浅色网格，不默认双列 |
| 时间顺序 | `timeline` | 活动、项目、人物采用不同节点气质 |
| 操作、赛程、实施路径 | `steps` | 已发生事件不要误做报名步骤 |
| 原稿引语 | `quote` | 不虚构说话人 |
| 功能或并列事项 | `features` | 不制造无意义胶囊标签 |
| 原稿图片 | `image`＋可选 `caption` | 等比例，按场景决定先图后文或图文交替 |
| 正式结论 | `closing` | 仅使用原稿支持的结论 |

无论密度如何：

- 强视觉锚点通常不超过5处。
- 大面积深色模块一屏不超过1个。
- 普通段落保持白底阅读。
