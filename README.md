# 公众号智能排版

一款面向微信公众号内容生产的智能排版 Skill。

它可以读取中文 Word（DOCX）、Markdown、纯文本、截图、链接或已有 HTML，自动识别标题层级、导语、金句、核心判断、并列要点、数据、流程、引语和图片，并根据文章类型推荐三套在结构、组件与配色上真正不同的现代排版方案。

用户选择方案后，只生成所选版本的微信公众号可复制富文本和纯净 HTML。

## 模型兼容性

这套 Skill 的语义识别规则、场景配方和设计规范不绑定单一模型。

* 在 ChatGPT、Codex 中，可以作为完整 Skill 使用。
* 在豆包、通义千问、Kimi、文心一言等支持长提示词和文件处理的中国大模型中，也可以导入或提供 `SKILL.md` 及配套资源使用。
* 不同平台的 DOCX、图片读取、Python 执行和 HTML 文件输出能力有所不同；缺少相应工具时，仍可使用其中的内容识别、风格推荐和排版规范，但最终效果会随平台能力有所差异。

## 主要功能

* 读取 Word、Markdown、纯文本、截图、链接和已有 HTML
* 自动识别文章类型、发布目的、主要读者和内容结构
* 自动识别标题、导语、金句、核心判断、要点、数据、流程、引语和图片
* 根据文章场景匹配首屏、章节标题、重点模块、图片节奏和结尾结构
* 先推荐 A、B、C 三套真正不同的排版方向
* 支持“A版式＋B配色”等组合选择
* 根据文章类型自动匹配版式、组件、颜色和设计密度
* 支持参考公众号文章、排版截图、链接或以前使用过的 HTML
* 生成微信公众号可一键复制的富文本版
* 生成不含脚本的纯净 HTML 版
* 使用微信公众号兼容性较好的行内样式
* 自动检查内容完整性、视觉层级和横向溢出问题

## 支持场景

目前支持但不限于以下常见文章类型：

* 政务调研
* 新闻通稿
* 科技产品
* 战略合作
* 活动回顾
* 教育案例
* 政策解读
* 人物故事
* 党建学习
* 生活活动
* 文化专题
* 商务发布

不同文章类型不仅会改变颜色，也会匹配不同的首屏结构、章节标题、重点卡片、数据模块、图片节奏和结尾形式。

## 默认工作流程

1. 一次性读取稿件，识别文章场景和内容层级。
2. 根据文章类型推荐三套结构和视觉风格不同的方案。
3. 等待用户选择 A、B、C，或组合版式与配色。
4. 只生成用户最终选择的一套方案。
5. 检查正文、数据、图片和网址是否完整。
6. 检查标题层级、金句、要点和普通段落是否识别准确。
7. 检查版式是否符合文章场景，而不是只改变颜色。
8. 交付可复制富文本版和纯净 HTML 版。

## 使用示例

可以向 ChatGPT、Codex、豆包或其他支持文件处理的大模型提出以下要求：

* “把这篇 Word 文章进行公众号排版，并生成可复制富文本和 HTML。”
* “先根据文章类型推荐三套不同的排版方案，等我选择后再生成。”
* “选择 A 版式＋B 配色。”
* “参考这张截图的排版气质重新设计，但不要直接复制。”
* “这是一篇科技产品稿，希望更有现代品牌专题风和 UI 设计感。”
* “自动识别文章里的标题、金句、要点和数据，再进行公众号排版。”
* “这是一篇党建学习稿，请根据内容匹配庄重但不老旧的版式。”
* “不要只改变颜色，首屏、章节标题和重点模块也要有明显区别。”

## 设计原则

* 不同文章类型不能只换颜色，版式结构也必须随场景变化。
* 首屏必须有明确的第一视觉，标题不能淹没在装饰中。
* 优先通过字号、字重、留白和对齐建立内容层级。
* 卡片只用于成组信息，不把每一段普通正文都装进卡片。
* 渐变色、英文标签、虚线、图标和装饰元素应克制使用。
* UI 设计感来自信息分区、索引、状态条、数据面板和稳定对齐。
* 不为了丰富页面而虚构金句、数据、步骤、标签或其他内容。
* 成品页面不展示 JSON、构建计划、代码块或调试信息。
* 优先保证复制到微信公众号后台后的样式稳定性。

## 文件结构

* `SKILL.md`：核心工作流、强制原则和审美底线
* `agents/openai.yaml`：Skill 的名称、简介和默认提示
* `references/semantic-structure.md`：标题、金句、要点、数据与段落层级识别规则
* `references/layout-library.md`：不同文章场景的版式结构配方
* `references/recommendation-system.md`：A、B、C 三套方案的推荐规则
* `references/design-system.md`：配色、字号、组件和微信兼容规范
* `references/case-patterns.md`：公开优秀案例的研究与提炼方法
* `scripts/wechat_html_builder.py`：微信公众号 HTML 生成脚本

## 使用提示

为了获得完整效果，建议同时提供：

* `SKILL.md`
* `references` 文件夹
* `scripts` 文件夹

如果使用的平台暂时不能执行 Python 脚本，也可以单独使用 `SKILL.md` 和 `references` 中的内容识别、方案推荐与设计规则，再根据平台能力生成排版结果。
