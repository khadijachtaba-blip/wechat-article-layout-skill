# 公众号智能排版

一款面向 ChatGPT / Codex 的微信公众号文章排版 Skill。

它可以读取中文文章或 Word（DOCX）稿件，根据文章主题自动判断适合的颜色和版式，并生成适合微信公众号使用的富文本与 HTML 文件。

## 主要功能

- 将 Word 稿件转换为微信公众号排版
- 根据文章主题自动选择配色
- 保留正文、图片、重点数据、署名和日期
- 生成可一键复制的富文本页面
- 生成不含脚本的纯净 HTML 文件
- 支持政务、教育、科技、党建、文化、乡村及商务等不同主题
- 使用微信公众号兼容性较好的行内样式

## 使用示例

可以向 ChatGPT 或 Codex 提出以下要求：

- “把这篇 Word 文章进行公众号排版，并生成可复制富文本和 HTML。”
- “沿用之前的版式，文章颜色根据内容自行判断。”
- “这篇文章使用红金色，排版庄重一些。”
- “保留文章图片、署名和日期，生成公众号版本。”

## 文件结构

- `SKILL.md`：Skill 的核心使用说明
- `agents/openai.yaml`：Skill 的名称和界面配置
- `references/design-system.md`：配色、字号和版式设计规范
- `scripts/wechat_html_builder.py`：微信公众号 HTML 生成脚本

## 工作流程

1. 读取并核对文章内容
2. 根据稿件主题选择视觉风格
3. 规划标题、导语、正文、图片和重点模块
4. 生成微信公众号兼容的富文本
5. 生成纯净 HTML 文件
6. 检查正文、图片、署名和日期是否完整
